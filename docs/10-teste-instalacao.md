- [ ] Cadastro de conta nova (ganha 250 moedas)
- [ ] Login com a conta demo (`demo@dotstudy.app` / `dotstudy123`)
- [ ] Desafio (modo normal, ou dificuldade "Demo" se o build tiver `VITE_DEMO_MODE=true`)
- [ ] Publicar post em texto

- [ ] Ranking do assunto estudado mudou após o ciclo/post

- [ ] Reiniciar o compose (`docker compose down` seguido de `docker compose up`) e os dados continuam lá
